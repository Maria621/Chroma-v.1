# Instituto Chroma — site institucional V3.1

Site multipáginas com dez páginas HTML, CSS, JavaScript e imagens Chroma. Abra `index.html` em navegador, ou sirva a pasta em um servidor estático.

## Melhoria visual
- Navegação agrupada, CTA em destaque e menu mobile acessível.
- Ajuste responsivo do hero e preservação de proporções das campanhas.
- Página de Novidades com ampliação de imagens e navegação por assunto.
- Páginas independentes: Escola, Essência, Metodologia, Estrutura, Experiência, Unidades, Novidades, Contato e Privacidade.

## Pendências antes do lançamento
Validar todos os endereços, fotos oficiais e contatos. O formulário não envia dados sem e-mail institucional validado e integração de backend. A página mantém `noindex` durante a fase de aprovação.
